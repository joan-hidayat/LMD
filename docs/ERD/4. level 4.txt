A. applications
applications
────────────────────────────
id                  BIGINT PK
code                VARCHAR(50) UNIQUE
name                VARCHAR(100)
slug                VARCHAR(100) UNIQUE
description         TEXT NULL
status              ENUM
created_at          DATETIME
updated_at          DATETIME
deleted_at          DATETIME NULL

Contoh:

1 | APOTEK      | Apotek Management System
2 | DISTRIBUTOR  | Distributor Management System
3 | TMS         | Training Management System

B. modules
modules
────────────────────────────
id                  BIGINT PK
application_id      BIGINT FK
code                VARCHAR(50)
name                VARCHAR(100)
slug                VARCHAR(100)
description         TEXT NULL
status              ENUM
sort_order          INT
created_at          DATETIME
updated_at          DATETIME
deleted_at          DATETIME NULL

Constraint:

UNIQUE(application_id, code)

Jadi:

APOTEK / INVENTORY

dan

DISTRIBUTOR / INVENTORY

boleh punya code yang sama karena application-nya berbeda.

D. package_modules
package_modules
────────────────────────────
id                  BIGINT PK
package_id          BIGINT FK
module_id           BIGINT FK
included            BOOLEAN

created_at          DATETIME
updated_at          DATETIME

Constraint:

UNIQUE(package_id, module_id)

Contoh:

Professional
│
├── Inventory      included = 1
├── Sales          included = 1
├── Purchase       included = 1
├── Accounting     included = 0
│                  additional_price = 150000
└── Multi Branch   included = 0
                   additional_price = 200000
