# CLAUDE.md — Central SaaS LMD

Repo ini adalah pusat ekosistem (LMD + `software-showcase` + `sample-mini-pos`).
Proyek masih tahap perancangan & pengembangan: password, credential, dan URL lokal sengaja hardcode.

## Aturan dokumentasi (wajib)
Setiap perubahan kode **dan** setiap analisis/temuan di repo mana pun dalam ekosistem dicatat di:
- `docs/LOG_EVALUASI.md` — tambah entri baru di paling atas bagian **Riwayat**; perbarui tabel **Daftar Temuan** (tambah `T-xx` baru atau ubah status yang diselesaikan, rujuk entri log & commit).
- `docs/EKOSISTEM_CARA_KERJA.md` — perbarui jika alur, endpoint, model data, atau status implementasi berubah.

Klaim di docs harus sesuai kode. Tandai fitur yang belum ada sebagai 🟡 sebagian / 📋 rencana, bukan seolah sudah jalan.
